# Принципы среды исполнения

## Кратко

DEOS — не только набор экономических идей, но и современная среда исполнения на базе Polkadot SDK. Проект следует действующим архитектурным подходам платформы, а не устаревшим представлениям, унаследованным от прежних версий Substrate.

Документация репозитория прямо относит ряд современных подходов SDK к обязательным условиям исправной базовой реализации парачейна: точное подключение компонентов по эталонному шаблону, исходные настройки асинхронного производства блоков, развёртывание через Omni Node и последовательная дисциплина конфигурации.

## Подтверждения в текущей реализации

Устройство рабочего пространства и сборка среды исполнения закрепляют этот выбор:

- Рабочее пространство использует линию библиотек Polkadot SDK `2606`.
- Паллеты применяют типизированную конфигурацию FRAME v2 и адаптеры, которыми владеет среда исполнения.
- Omni Node заменяет собственный узловой пакет внутри репозитория.
- XCM, идентичность активов, API среды исполнения и веса остаются явными точками интеграции.
- Планирование V3 остаётся отключённым, пока не будет пройдена отдельная проверка готовности.

Для DEOS это не рекомендации по стилю. Они определяют текущую границу платформы и обязательства по проверке.

## Почему об этом нужно знать

Если читать только экономические документы, можно упустить существенную часть проекта: фреймворк намеренно строится на современной архитектуре парачейнов, а не только на собственных идеях отдельных паллетов.

От этого зависит, как участники проекта должны рассуждать о сборке среды исполнения, проверках и безопасности обновлений.

## Связь с экономической системой

Эти архитектурные принципы относятся к инфраструктуре, но поддерживают весь экономический уровень:

- Правильное соединение коллаторов и среды исполнения необходимо для выпуска блоков.
- Способ интеграции активов определяет поддержку внешних активов.
- Выбранные подходы к консенсусу и асинхронному производству блоков влияют на работу среды исполнения в текущей линии запуска.
- Omni Node приближает развёртывание к действующему стандарту исходной экосистемы.
