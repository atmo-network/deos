# DEOS Wiki

## Summary

DEOS is a forkable runtime framework for economies that need explicit rules for issuance, liquidity, staking, governance, and automation. TMCTOL is the reference economic standard on DEOS, not a requirement for every instance.

## Explore DEOS

- [DEOS Framework Overview](overview/deos-framework.en.md) — What the framework provides and what a fork decides.
- [Actors System](overview/actor-system.en.md) — How DEOS admits and runs bounded protocol work.
- [End-to-End Flows](concepts/end-to-end-flows.en.md) — Worked examples of routing, actor wakeup, retries, and staking.
- [TMCTOL Standard](concepts/tmctol-standard.en.md) — How one-way issuance and treasury-owned liquidity fit together.
- [Domain Map](concepts/domain-map.en.md) — How the economic, runtime, governance, and client domains connect.

The [Core Terms](core-terms.en.md) explain unfamiliar vocabulary; the [Newcomer FAQ](newcomer-faq.en.md) answers common questions.
