# С чего начать

Из исходников можно собрать и проверить эталонную среду исполнения без локальной ретрансляционной цепи и веб-клиента. Запуск сети — отдельная задача оператора.

## Собрать среду исполнения и проверить метаданные

На Linux x86-64 установите системные инструменты, указанные в исходной поставке. Затем выполните из её корня:

```bash
./scripts/setup-environment.sh framework
./scripts/03-build-runtime.sh --output "$PWD/deos-development.wasm"
./scripts/export-papi-metadata.sh \
  --wasm "$PWD/deos-development.wasm" --output "$PWD/deos.scale"
```

Укажите новый выходной файл Wasm. Скрипт обращается к API метаданных выбранного Wasm, проверяет побайтовое совпадение и не подменяет результат метаданными нативной сборки. На выходе — Wasm для разработки и его метаданные, а не артефакт, допущенный к запуску сети. Для проверки исходников и независимого встраивания пакетов используйте `./scripts/validate-local.sh framework`.

## Запустить локальную сеть с принятыми входными данными

Для запуска нужны полный репозиторий и отдельно принятый операторский комплект для Linux. Сборка из исходников не заменяет этот комплект. Проверьте его командой скрипта 01 с `--check-reference-bundle`, затем установите через `--import-reference-bundle` с `--bundle-output`. Используйте входящие в комплект среду Node, командный интерфейс Zombienet, узел Omni Node и спецификацию цепи с начальным хранилищем и принятым Wasm. Отдельно установите закреплённые исполняемые файлы ретрансляционной цепи и рабочих процессов. Совпадение номера версии или свежая сборка Wasm для разработки не заменяют принятые файлы.

После выбора этих входных данных укажите существующий рабочий каталог, который принадлежит вам и не содержит `zombienet-network`, и новый путь для результатов проверки. Точные переменные окружения перечислены в `./scripts/05-spawn-zombienet.sh --help`. Запустите скрипт 05 в эталонном режиме по умолчанию, не отправляя процесс в фон. Из другого терминала проверьте настроенные локальные RPC командой `./scripts/06-network-smoke.sh`. Она наблюдает ограниченное продвижение финализации ретрансляционной цепи и парачейна и не отправляет транзакции.

## Открыть необязательный веб-клиент

В полном репозитории можно отдельно запустить клиент для разработки. Сначала выберите в своём терминале закреплённые в репозитории версии Node и npm:

```bash
./scripts/setup-environment.sh client
npm --prefix web-client run papi:generate
npm --prefix web-client run dev
```

Клиент открывается и без сети. Для просмотра актуального состояния нужна доступная цепь с совместимыми метаданными.
