## Measurements

Current runtime permits at most 9,000 User Crossing memberships on one feed, below the required 10,000-User fixture. Independently, generated component-wise Crossing admission permits four candidates per block. Therefore 100 eligible blocks can materialize at most 400 candidates, only 4% of the required population, before scheduler/effect service is considered.

The configured 9,000-User reachable population requires at least 2,250 uncontended detector blocks; the 10,000 total-member bound requires 2,500. These are generated admission lower bounds, not extrapolations from System schedule throughput.

## Derived Metrics

`400 / 10,000 = 4%` maximum target coverage in the required window. Both fixture admission (`9,000 < 10,000`) and detector horizon (`2,500 > 100`) independently falsify the current target.

## Statistical / Variance Notes

Deterministic configured bounds and generated two-dimensional admission; no sampling, censoring or sustained-service inference.

## Result

The required User/reactive target is not constructible and cannot complete under current production Crossing admission. Existing System witnesses cannot repair either falsifier.

## Interpretation

This is an explicit evidenced reachable-population constraint, not an architecture regression claim or permission to substitute a smaller/System profile.

## Decision

Accepted negative result. Current production cannot satisfy performance-assurance §2.1/§2.2 and the same Crossing ingress bound blocks §2.3 before Task outcome. Parent acceptance must retain this explicit constraint or reopen target/geometry through its owning contract.

## Rejected Alternatives and Tradeoffs

- `System proxy`: Rejected because target identity is User ObservationCrossing.
- `9,000 as 10,000`: Rejected because configured admission makes the fixture nonconstructible.
- `Scheduler throughput substitution`: Rejected because detector materialization alone exceeds the window.

## Validity

Establishes target impossibility under current bounds and binding. Does not measure a smaller accepted target, sustained fairness or Task throughput. Population, target, binding or Crossing admission changes require review.

## Follow-Up / Next Gradient

Carry the explicit constraint into EXP-0066 and G8; do not claim the historical target or replace it with System evidence.

None. C1 freeze and current architecture remain unchanged.
