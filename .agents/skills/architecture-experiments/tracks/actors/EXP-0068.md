## Decision Question

Can one complete consumed-source User Opening completion atom qualify Pipeline collection, StopCycle completion and applicable hold reconciliation without recharging outer FIFO discovery/consumption?

## Governing Specification

- `Owners`: `template/pallets/actors/docs/specification.en.md` defines independent Pipeline/Action fees and exact state holds; `docs/actors-resource-policy.specification.en.md` defines sole Control ownership and component-wise settlement containment.
- `Invariants`: Preserve C1, public admission, Manual useful readiness, class-neutral FIFO, cutoff, Q1, custody and fee semantics. No production binding changes in this preparation.
- `Reopen trigger`: A semantic or custody failure must return to its owning implementation/specification; measurements cannot ratify it.

## Context and Hypothesis

EXP-0067's smallest source qualification found two incompatible measurement boundaries. `scheduler_paged_execute_opening_max` measures full FIFO service of a maximum-length User Contract, a resolution skip, Running publication and hold release. `scheduler_inner_opening_complete_min` measures consumed-source System StopCycle completion. The first neither attains completion nor excludes the already charged outer source prefix. Reusing its aggregate as a disjoint inner completion atom is unqualified.

This Leaf owns the missing numeric inner-completion input, independently of EXP-0067's production selector decision. The existing User full-Opening and hold measurements remain scoped inputs, not a universal completion envelope. The hypothesis is a class-qualified version of the existing minimal completion fixture at the same consumed-source boundary.

## Controls

- `Geometry`: Manual Persistent Contract, StopCycle at Step 0, no predicates or Opening captures; reachable tail LastFunding ingress; `t = 0..=ceil((MaxContractSteps-1)/4)`.
- `Changed variable`: Actor class and its required collection/hold work; public User admission and ledger state intentionally differ from System setup.
- `Boundary`: Real state/admission/current Step loading and source consumption happen before measurement. `execute_reachable_step_inner` owns plan construction, execution, publication and applicable hold reconciliation.
- `Exclusions`: Outer FIFO, temporal/Crossing rearm, authored close, predicated completion, failure/retry/progress, invoked Task effects and generic host dominance.

## Statistical / Variance Notes

Native construction is deterministic. Both reference runs use one unchanged compiled Wasm and identical sampling configuration; `--extra` only admits the User diagnostic. Minimum-duration repetition produced 3,000 time/150 DB samples for User and 4,000/200 for System, not identical sample counts. Integer component rounding heavily weights t=0..2; the tables expose the smaller t=3 sample set. Raw timing tails are retained rather than discarded. No order-reversed timing study, whole-block throughput inference or host-independent latency claim is made. The deciding I/O mismatch occurs identically in all 48 User DB samples at t=1 and does not depend on timing statistics. Benchmark genesis logs report unavailable LP-backed collator security; these profiles do not exercise that subsystem and no production-genesis liveness is inferred.

The partitioned cohort retains the same sampling configuration and nearest-rank, unfiltered raw quantiles. It contains 6,940 time/347 DB single samples and 2,000 time/100 DB tail samples; only two DB observations land at t=3. This is standard FRAME model evidence for the attained branch, not a latency stress test or universal worst-case timing guarantee.

## Interpretation

The inner boundary is attainable and includes the intended User collection/hold work without outer FIFO consumption. The initial defect was calibration: a single linear regression smeared a real zero-versus-nonzero funding-hold branch. Rejecting the fit does not reject the User inner owner or its legal fixture. The source-defined partition preserves the postconditions and removes the deterministic I/O underfit without manual coefficient changes or borrowed accounting. The original System comparison is a same-binary control for the rejected unsplit cohort, not authority to use System accounting for User. The partitioned candidate qualifies the attained User branch witnesses only. Minimal current-Step captures and t alone do not identify arbitrary Contract-head/tail geometry, so these coefficients are not a universal production envelope and cannot be selected merely from those scalar fields. EXP-0067 must prove its live selection domain or obtain a stronger owner; no relaxed geometry rule is accepted here.

## Decision

Accepted for the attained reference fixture domain only. Select A-partitioned as the complete inner branch evidence: single-Step `850,786,000 / 7,477`, and positive-tail `1,241,032,549 + 40,467,609*t` RefTime with `10,164 + 2,834*t` estimated ProofSize, including their generated DB charges. The unsplit fit remains rejected. This accepts neither arbitrary User geometry nor a production binding; EXP-0067 owns live-domain qualification, exact selection and containment before complete regeneration. Stop measuring the satisfied branch witnesses.
