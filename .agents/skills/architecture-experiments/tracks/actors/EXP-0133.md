## Decision Question

What complete generated ownership matrix must bind every reachable current-lineage path and retained object so read-only selection, refused and rollback work, state mutation, effects, settlement, storage collateral and mandatory suffixes are all paid without overlap subtraction, shallow fixtures or free fallback work?

## Governing Specification

- `Exact section`: `BACKLOG.md` N5.2; `template/pallets/actors/docs/specification.en.md` §2.3 and fee/resource contracts; EXP-0120–EXP-0132 current lineage.
- `Invariant`: Before any bounded selector or mutation runs, one generated descriptor covers its complete legal domain and worst-case proof. Reservation is not settlement; logical access is not a distinct trie key; Control never silently pays Task effects or retained bytes. Every mandatory suffix is admitted before the first irreversible write.
- `Reopen trigger`: One supported path, refusal, rollback, storage class, proof root, effect callback or maintenance suffix lacks an exact owner; two owners subtract an unproved overlap; or a generated fixture cannot reach the legal maximum geometry.

## Context and Hypothesis

- `Current architecture`: The current lineage fixes stable process ownership, Pending checks, one Live/Pending ring, deadline-backed Sleep/Park, current execution/retry, atomic transfers, typed lifecycle and generation-safe cleanup. N5.1 removes old fallback authority. Numeric generated bindings do not yet exist for this representation.
- `Reason`: A bounded structure is not paid merely because its cardinality is finite. Selectors can consume proof and CPU before deciding no mutation; destination refusal and transaction rollback still execute work; effects and settlement have independent failure domains; retained bytes and cleanup capacity are not dispatch Weight.
- `Hypothesis`: Generate one descriptor family per path phase. Each descriptor declares prerequisite reads, distinct-key/root-inclusive proof domain, CPU components, staged writes, mandatory rollback/refusal suffix, effect reservation, actual settlement and retained-state delta. Composition sums disjoint owners and uses measured joint owners only where one benchmark executes the exact combined path.
- `Materiality`: Freeze complete ownership and fixture domains. Exact coefficients, encodings, benchmark implementation and production bindings remain implementation/N7 work.

## Measurements

### Owner Dimensions

Every generated descriptor reports these dimensions independently:

```text
PathOwner = prerequisite reads + selector CPU + distinct-key/root proof
          + staged writes + mandatory refusal/rollback suffix
EffectOwner = requested reservation → outstanding reservation → actual settlement
StateOwner = retained-byte maximum + terminal cleanup-capacity class
```

A logical field read does not imply a distinct trie key, and repeated access to one key is not multiple root proofs. Conversely, two storage items sharing a conceptual object are not one key. Root-inclusive proof is measured from the production benchmark backend. A composed path receives no overlap discount unless one generated benchmark measures that exact composition at its full legal geometry.

### Fixture and Accounting Rules

- Each benchmark constructor proves it reached the requested legal geometry; setup assertions fail rather than silently generate a shallow case.
- Required fixtures include empty, singleton, maximum population, full capacity, fragmented pages, deepest deadline path, head/middle/tail unlink, stale generation, cold read and hit/coalesced paths.
- Refused and rollback benchmarks include every read and CPU operation performed before return and every staged write whose transaction is reverted.
- Weight reservation records requested, admitted outstanding and actual settled quantities separately. Unused reservation is released; executed Control is not refunded because a Task effect failed.
- Generated storage maxima feed retained holds; generated cleanup maxima feed terminal bonds/debt classes. Neither is added to dispatch Weight as a fictional execution charge.
- Mandatory suffix coverage is preflighted before mutation. If a host cannot reserve it, the ordinary transition refuses unchanged; presecured revocation/cleanup uses its non-borrowable owner.

## Result

Candidate A closes the conceptual resource domain: selectors and negative outcomes are paid before execution, movements include capacity/refusal/rollback suffixes, effects settle independently, and retained bytes/debt remain distinct from dispatch Weight. Every selected path has a maximum-geometry fixture contract and no old fallback may absorb omitted work.

## Interpretation

The unit of Weight ownership is a reachable physical phase, not an extrinsic name and not a successful write. Read-only decisions, failed capacity checks and rollback consume resources. Conversely, charging every conceptual access separately invents work when accesses share one key. Complete coverage therefore requires exact key/proof topology plus explicit phase boundaries, not conservative prose or subtraction by intuition.

## Decision

Accept Candidate A as the N5.2 generated resource-domain matrix. Implement one descriptor family covering every listed path and retained class; admit complete selectors and mandatory suffixes before mutation; benchmark all declared maximum/refused/rollback geometries; separate reservation from settlement and dispatch Weight from collateral/debt; compose only disjoint owners or directly measured joint paths. Runtime realization and coefficients remain open.

## Rejected Alternatives and Tradeoffs

| Candidate | Decision | Evidence-backed reason |
| --- | --- | --- |
| Charge only successful mutations | Rejected | Makes negative checks, refusal and rollback free |
| One monolithic worst-case constant | Rejected | Hides path reachability and can overcharge unrelated effects while still omitting suffixes |
| Sum logical field accesses as trie keys | Rejected | Invents proof work and obscures actual distinct-key topology |
| Subtract expected overlap | Rejected | Cache/proof overlap is unproved unless exact composition is measured |
| Settle requested effect reservation in full | Rejected | Confuses admission authority with actual executed effect |
| Use Task Weight to fund Control or storage | Rejected | Cross-subsidizes distinct owners and failure domains |
| Benchmark only warm/hit and shallow fixtures | Rejected | Does not cover legal cold, fragmented, deep or full state |
| Defer cleanup to ordinary idle | Rejected | Violates mandatory reclamation liveness |

The tradeoff is a larger explicit benchmark surface and generated descriptor schema. It buys reviewable completeness, precise failure accounting and bounded host embedding without imaginary free CPU work.
