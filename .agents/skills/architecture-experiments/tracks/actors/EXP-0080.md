## Decision Question

Do recorded key-path unions plus an independent committed-root witness cover every execution-proof node in the retained 18-block matched Manual/Cadenced cohort?

## Governing Specification

- `Owners`: `docs/actors-performance-assurance.specification.en.md` (production evidence); `docs/actors-resource-policy.specification.en.md` (independent resource dimensions); `template/pallets/actors/docs/specification.en.md` (scheduler invariants).
- `Invariant`: Preserve frozen C1, FIFO, Q1, cutoff and separate proof bytes from generated Weight and invocation counts.
- `Reopen trigger`: Demonstrated semantic contradiction requires specification review; raw proof sharing does not authorize a Weight discount.

## Context and Hypothesis

- `Current architecture`: SDK recorder paths share trie nodes; keyless execution nodes require independent coverage.
- `Reason`: Key counts and total proof size cannot explain node overlap or the remainder.
- `Hypothesis`: Root-scoped keyed paths plus committed-root reconstruction cover the complete execution-node set in the matched cohort.
- `Materiality`: Zero uncovered raw-node bytes in every retained block, not a throughput improvement.
