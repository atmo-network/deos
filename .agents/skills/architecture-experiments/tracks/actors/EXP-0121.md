## Decision Question

What is the smallest runtime-owned discovery and activation-check transition that covers every supported current-state Actor start source without treating hints as effects, scanning the Actor population, dropping overload, or retaining unsupported event-history semantics?

## Governing Specification

- `Exact section`: `BACKLOG.md` N0.2 capability matrix and N3.1; `template/pallets/actors/docs/specification.en.md` current-state Trigger replacement.
- `Invariant`: A notification or deadline makes exactly one current-generation check owed. Only the later current-state check may admit Live work; source history never authorizes an effect.
- `Reopen trigger`: A supported profile cannot identify a bounded direct source, bounded shared-key traversal, or deterministic review deadline capable of retaining one owed check under saturation.

## Context and Hypothesis

- `Current architecture`: Manual uses direct Actor lookup; certified address ingress resolves the destination through `SovereignIndex`; observation publication uses bounded feed subscriber pages and resumable dirty-feed traversal; AtTime/Cadenced use bounded wakeup deadlines. Those paths currently materialize legacy Trigger readiness directly.
- `Reason`: N3 requires autonomous current-state discovery before selecting a concrete Live/Sleep/Park/Pending carrier.
- `Hypothesis`: Existing source routes can terminate at one common pending-check boundary before current applicability and Live admission, while incomplete notification domains use a deterministic review deadline.
- `Materiality`: Select the logical transition and overload contract only. EXP-0120 owns process/reference geometry; N3.5 owns exact carrier encoding; N3.7 owns registration/acknowledgment interleavings.

### Supported Source Inventory

| Supported profile/source | Runtime discovery route | Bound and current check | Negative/unknown return |
| --- | --- | --- | --- |
| Manual | Authorized direct `ActorId` lookup | One generation; lifecycle, authority and current start state | Typed reject or idempotent no-op/Park without retry reset |
| Balance-reactive ingress | Certified destination resolved by direct `SovereignIndex` | One destination; current spendable balance/provider/predicates | Exact dependency Park or timed review |
| Observation current/change | Dirty feed plus resumable bounded subscriber pages | One priced page; current typed value, validity, age and predicates | Complete feed/deadline Park or timed review |
| AtTime | Indexed one-shot deadline | One due reference; current time and consumption state | Sleep until due, then terminal after its one Cycle |
| Cadenced | Indexed recurring deadline | One due reference; latest current deadline | Sleep to next deadline; missed periods coalesce |
| Timed fallback | Deterministic review deadline | One due reference; entire current start condition | Refresh review/Park or admit Live |

`ObservationCrossing` is excluded because a transient crossing cannot be reconstructed from current state. Broad `AddressEvent` is excluded unless certification reduces it to exact current account/asset dependencies; sender and transfer history are not start authority.

### Selected Transition

```text
bounded hint or due deadline
→ resolve exact slot + generation
→ stale/disabled/busy/Live/retry/already-Pending: typed reject or coalesce
→ durably retain PendingCheck(slot, generation)
→ current activation check
   false + complete wake plan → Park
   false/unknown + deadline  → Sleep/review
   true + complete admission → Live, first eligible B+1
   capacity/resource refusal → retain Pending; never recreate source history
```

A cheap check may share a transaction with hint handling or admission only when the complete suffix is pre-admitted and charged. The roles remain distinct: a hint carries no predicate result, effect authority, future capacity, or second Cycle. Shared traversal advances only after a stale reference or durable pending acknowledgment; full Pending capacity is typed backpressure, not a dropped check. Busy hints do not reset cursor, retry count, round guard, fees, or recurrence.

## Result

Manual and certified balance ingress already have direct bounded resolution; observations already have keyed bounded traversal; temporal schedules already have indexed deadlines. Timed review closes incomplete notification domains. No supported current-state profile requires whole-population polling or event-history authority.

## Interpretation

The common semantic unit is not a Trigger occurrence but one owed current check for one Actor generation. Generation binding prevents stale hints from targeting replacements. Durable coalescence before source acknowledgment preserves overload; current rereading makes intermediate source history unnecessary. Carrier bytes, fee amounts, Park Certificate completeness and interleaving proofs remain independent downstream obligations.

## Decision

Accepted as a research result and sole N3.1 logical boundary: direct Actor/account lookup, bounded shared-feed traversal, indexed deadlines, or deterministic timed review creates or proves one generation-bound Pending check. Only current applicability may Park, Sleep/review, or admit Live. Stop after this one candidate; implementation proceeds through N3.2–N3.8 rather than adding another discovery engine.

| One queued hint per occurrence | Rejected | Reintroduces history and busy accumulation |

## Validity

- `Establishes`: Supported discovery routes, one pending-check semantic boundary, coalescence rule, and explicit overload disposition.
- `Does not establish`: Concrete storage encoding, fees, Park Certificate fields, ring implementation, or production Weight.
- `Known limitations`: Current source still implements legacy Trigger readiness; this is target architecture, not shipped architecture truth.
- `Invalidation triggers`: A supported source or host completeness assumption changes, or bounded acknowledgment cannot be realized.
- `Residual qualitative insight`: Discovery identifies work owed; only current state decides work applicable.

## Follow-Up / Next Gradient

