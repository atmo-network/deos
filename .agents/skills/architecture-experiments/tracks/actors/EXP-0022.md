## Decision Question

Does exact one-third Actor Control with the Shared remainder split equally between Actor effects and user dispatch materially improve the accepted 30/35/35 baseline without unacceptable economic-capacity loss?

## Governing Specification

- `Exact section`: `docs/actors-resource-policy.specification.en.md` → `2. Resource Algebra` and `3. Economic Zipper`.
- `Invariant`: Preserve component-wise accounting, strict FIFO, Q1, class neutrality, work conservation, deterministic remainder ownership, and at least approximately one third each for Control, Actor effects, and user dispatch.
- `Reopen trigger`: Actor Control above one third is excluded; all further throughput gains must optimize execution inside the one-third envelope.

## Context and Hypothesis

- `Current architecture`: EXP-0006 selected fixed 30% Control and equal 35%/35% Shared base turns.
- `Reason`: One third is the declared maximum Control share and provides a symmetric DEOS resource boundary.
- `Hypothesis`: Raising Control from 30% to floor one third yields a smaller but measurable traversal gain while retained one-third effect/user turns remain sufficient.
- `Materiality`: Require at least 5% more traversal throughput than 30/35/35 with zero semantic failures and exact base-turn preservation.

## Result

A1 completes W1/W2 at block 679 versus A0 block 746 and W3 at block 679 versus A0 block 765. Every continuous user dispatch remains admitted and W3 has zero failed Steps. W4 exact partition and borrowing tests pass.

## Interpretation

A1 clears the 5% materiality threshold in every throughput workload. The gain is 9.9% for Transfer and 12.7% for mixed effects while each guaranteed effect/user base turn falls only 4.76%. Equal thirds also establishes the declared hard Control ceiling; remaining throughput pressure transfers to execution-authority geometry.

## Decision

Accept A1 as the production resource partition. Actor Control is floor one third of schedulable Weight; Shared Economic owns the remainder; Actor and user base turns split that remainder floor/remainder. No later optimization may increase Actor Control above one third.

## Rejected Alternatives and Tradeoffs

| Candidate | Decision | Evidence-backed reason |
| --- | --- | --- |
| Control above one third | Excluded | Violates the declared minimum thirds for Actor effects and user dispatch |
| Dynamic ratio | Excluded | Adds consensus policy/state complexity without earned need |

## Validity

- `Establishes`: Comparative behavior of 30/35/35 and exact one thirds for declared profiles.
- `Does not establish`: A throughput SLA or permission to exceed one-third Control.
- `Known limitations`: Profiles admit one continuous user call rather than saturating all user capacity; exact W4 algebra owns the guaranteed envelope.
- `Invalidation triggers`: Changed Weight, authority geometry, block limits, or workloads.
- `Residual qualitative insight`: Equal thirds is a hard allocation boundary, not a substitute for authority optimization.
