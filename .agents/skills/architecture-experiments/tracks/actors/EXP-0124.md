## Decision Question

How is every no-effect current-state turn paid or bounded without allowing cheap heads, duplicate hints, payment failure, stale references, or adversarial condition changes to bypass FIFO or consume unbounded consensus work?

## Governing Specification

- `Exact section`: `BACKLOG.md` N3.4; `template/pallets/actors/docs/specification.en.md` §§2.3, 7.3–7.7, and 8.3–8.5.
- `Invariant`: Every admitted Actor-specific control unit has one complete generated Weight owner before execution; User work has committed fee authority and System work consumes bounded host allocation, while the valid FIFO head cannot be bypassed.
- `Reopen trigger`: A reachable no-effect path performs Actor-specific reads or mutation without prepaid User authority or bounded System allocation, or a refusal lets later work overtake the valid head.

## Context and Hypothesis

- `Current architecture`: Four fee owners already separate useful Trigger occurrence, complete admitted Pipeline control, invoked Action effect, and process creation/state. Actor Control has a hard one-third ceiling and strict FIFO stops at an unserviceable valid head.
- `Reason`: The current-state design adds Pending checks, Park invalidations, timed reviews, resident false checks, and generation-stale references; each must have explicit economic and service authority before carrier selection.
- `Hypothesis`: One coalesced activation-check unit is the correct negative-work atom. For Users its complete maximum Trigger-control fee is secured when Pending is materialized; for Systems the same generated maximum is admitted against bounded Actor Control allocation. Pipeline and Action charging begin only after a true check admits Opening/effect.
- `Materiality`: Freeze ownership, refusal, and adversarial fairness witnesses only. Generated numeric Weight, fee conversion, exact carrier encoding, and production throughput remain downstream.

`Trigger-control fee` keeps the existing Trigger Fee boundary: it prices only the complete generated detection, matching, materialization, current applicability check, and negative disposition of one useful occurrence. It does not buy Pipeline control or Action effects. Physical workers may split that unit across blocks only while retaining exact prepaid authority and a bounded remaining cursor; one admission cannot authorize unbounded polls or retries.

### Fairness and Griefing Rules

1. Strict FIFO is cost-blind. Cheap, User, System, false, or likely-successful work cannot overtake the earliest valid eligible head.
2. A complete generated maximum is admitted component-wise before Actor-specific work. If it cannot fit, no partial mutation occurs and the pass stops at that head.
3. A maximum legal transition may consume the block's Actor service opportunity. This is bounded paid service, not structural starvation; admission bounds must nevertheless fit the profile's guaranteed Actor Control envelope.
4. Tiny-credit storms can create no unpaid useful User check: each distinct unlatched obligation must secure its full fee, while duplicates coalesce without resetting retries, deadlines, or next-Cycle readiness.
5. Always-false programs pay each independently due review/check unit; they cannot obtain perpetual polling from Creation Fee, state hold, or one Trigger fee. Always-true programs proceed through independently paid Pipeline and Action boundaries.
6. Condition toggling coalesces behind one Pending obligation. Revisions preserve the newest unacknowledged fact but do not mint additional queue position or service credit.
7. Fee/provider/observation unavailability is a repairable prerequisite refusal, not permission to skip the head or spend unlimited retry work. A bounded revisit occurs only under retained prepaid authority or a newly admitted unit.
8. System Actors pay no synthetic fee, receive no priority, and consume only explicit generated Actor Control allocation. Sustained System demand cannot exceed the one-third ceiling or borrow Shared Economic capacity.
9. Stale cleanup has a bounded per-pass owner and may expose the next head, but repeated stale churn must be capped and measured; valid-head service cannot depend on unbounded prefix drainage.
10. Sustained external demand retains the Shared Economic portion. Optional lending may move unused Actor Control outward only and cannot alter cutoff, Q1, or FIFO.

## Result

The smallest safe unit is one complete current-state activation check, not one hint, one predicate read, or one unlimited retry stream. A User useful occurrence secures that unit's generated Trigger-control maximum before durable Pending authority; a System occurrence receives the same bounded service only through Actor Control allocation. False results, duplicate hints, and repairable refusals create no free second authority. Pipeline and Action owners remain independent and begin only after their existing admission boundaries.

## Interpretation

Charging only successful Cycles would subsidize adversarial false checks, while charging every duplicate hint would double-charge coalesced state and permit griefing the Actor's balance. Pre-admitted check authority prices the actual bounded consensus obligation. Strict no-bypass makes expensive or temporarily blocked heads visible rather than hiding them through semantic reordering; profile admission and generated Weight must ensure every maximum legal head can eventually fit.

## Decision

Accepted as the sole N3.4 logical policy: treat one coalesced complete activation check as the negative-work atom. Secure its complete generated Trigger-control fee before a User Pending transition, or admit the same maximum against bounded Actor Control for System work. Retain exact authority across bounded repairable retries, require a fresh authority for each later timed review, reject duplicates before Actor-specific evaluation, preserve strict valid-head FIFO without cheap-head bypass, and classify structural faults separately from resource/prerequisite refusal.

## Rejected Alternatives and Tradeoffs

| Candidate | Decision | Evidence-backed reason |
| --- | --- | --- |
| Charge only successful Opening/Pipeline | Rejected | Subsidizes always-false and toggling current-state checks |
| Charge every incoming hint | Rejected | Double-charges coalesced state and lets third parties drain User Actors |
| One Trigger fee buys indefinite polling/retry | Rejected | Creates unbounded consensus liability from one bounded payment |
| Skip an expensive or underfunded valid head | Rejected | Breaks FIFO and makes adversarial priority depend on estimated cost or wealth |
| Give fee-exempt System Actors priority | Rejected | Fee exemption is host ownership, not scheduler preference |
| Treat provider/fee refusal as permanent fault | Rejected | Conflates repairable prerequisites with invariant corruption and can destroy valid custody/process authority |
| Treat stale references as ordinary paid checks | Rejected | A stale physical record has no live payer or semantic execution authority |

## Validity

- `Establishes`: Negative-work atom, User/System owner split, retry authority bound, coalescence, no-cheap-head-bypass, and mandatory adversarial witness set.
- `Does not establish`: Numeric Weight/fees, exact cursor/storage encoding, review cadence, saturation throughput, or production viability.
- `Known limitations`: Target carrier and generated Trigger-control branches are not implemented; existing Trigger benchmarks do not yet include the future complete Pending-check geometry.
- `Invalidation triggers`: Any supported no-effect path cannot fit one bounded owner, one payment must authorize unbounded revisits, or strict FIFO cannot meet profile admission bounds.
- `Residual qualitative insight`: Fairness requires pricing admitted obligations, not outcomes or raw hints.
