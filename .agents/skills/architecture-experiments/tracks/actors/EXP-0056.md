## Derived Metrics

A3 component-wise contains every other removal branch and the accepted EXP-0042 maximum-Step Suspended/Crossing public-close point. The selected complete removal/repair candidate is therefore `1,928,069,000 / 96,741 +70 reads / 44 writes`, totaling `8,078,069,000` RefTime under pinned RocksDB. This is selection among mutually exclusive complete close branches, not an additive heap allowance, aggregate subtraction or isolated repair coefficient.

## Statistical / Variance Notes

Each deciding branch uses 50 steps × 20 repeats on one source/Wasm. Fixed benchmarks have no model component; generated output selects conservative fixed RefTime. Earlier singleton samples remain construction/access evidence only and are not used for timing dominance.

## Result

The complete admitted reference removal branch map selects the final Tick Reference/root-downward repair atom at `1,928,069,000 / 96,741 +70R/44W`. It contains mixed Reference retention/unlink, saturated upward repair, tail-only removal and the retained admitted public-close owner component-wise. No generated fragment is installed.

## Interpretation

Heap population dominates shallow mixed-page cleanup, and downward root repair dominates upward and tail-only alternatives in every Weight component on the common Wasm. Because every profile measures public close through completion, Contract/Run/lifecycle/source work is already included exactly once. EXP-0063 must select this complete atom for populated removal rather than add it to EXP-0042 or a generic close coefficient.

## Decision

Accepted for the admitted reference removal/repair domain. Select exactly one inclusive complete close branch; the conservative bound is `1,928,069,000` pre-DB RefTime / `96,741` estimated ProofSize plus 70 reads and 44 writes (`8,078,069,000` pinned-DB RefTime). Do not install the diagnostic fragment or add separate close, Run, Waiting, heap, page-unlink or lifecycle work. EXP-0065 owns exact regeneration and any requalification required by a changed admitted domain.

## Rejected Alternatives and Tradeoffs

- Adding heap repair to EXP-0042's inclusive public-close atom is rejected as duplicate charging.
- Subtracting mixed or tail close aggregates to synthesize an isolated heap coefficient is rejected because setup and retained state differ.
- Selecting upward repair from changed-page intuition is rejected: the measured root/downward branch is larger in all Weight components.
- Reopening frozen C1 topology or beginning residual optimization is rejected; this owner now has a conservative measured bound.

## Validity

- `Establishes`: Common-Wasm 50 × 20 costs and component-wise containment for ordinary mixed Reference retention/unlink and complete legal downward/upward/tail final-key repair branches at the accepted reference host population.
- `Does not establish`: A new admission domain, publication encoded-cell closure, exact production Weight/artifact identity, integrated throughput or isolated heap costs.
- `Known limitations`: The selected bound is a complete public-close branch, not a reusable standalone repair allowance. A later changed admission/Weight binding may require scoped requalification before G5 acceptance.
- `Invalidation triggers`: A changed measured body, Waiting topology, close/removal selector, host domain, source/Weight/Wasm identity or acceptance rule.
- `Residual qualitative insight`: Select complete branch owners; population and repair direction matter more than the benchmark's nominal close label.
