## Decision Question

Does every production Actor Control phase have exactly one sound Weight owner, with no omission and no double charge?

## Governing Specification

- `Owners`: `template/pallets/actors/docs/specification.en.md` (sole ownership, lifecycle/Trigger/Pipeline/Action semantics, placement and scheduler); `docs/actors-resource-policy.specification.en.md` (component-wise admission/actual settlement, equal-thirds block policy); `docs/actors-performance-assurance.specification.en.md` (evidence and target).
- `Frozen physical input`: [EXP-0025](./EXP-0025.md) C1 Architecture Freeze. No change to FIFO, ticket chronology, Q1, causal floor, primary/reference ontology, source/successor atomicity or sole execution owner.
- `Semantic oracle`: A0 SHA-256 `8746e423168309975e509be91e4eb06fdf0eb0b43369d75f1ee62202a4341678` remains frozen; use only for relevant semantic equivalence, never as a Weight oracle.
- `Scope`:

- Own Trigger/Pipeline/Action control ownership, Action fee-collection Control cost, invocation events and User state-hold work.
- Own source consumption, successor publication, cleanup, lifecycle terminal work, Waiting placement/removal and independent Cadenced rearm phase boundaries.
- Distinguish semantically required User/System differences, actual versus maximum control settlement and no-double-charge.
- Keep four separate columns: semantic owner, physical storage owner, Weight owner and monetary fee owner. A semantic operation may touch several stores but has one complete charging boundary; storage ownership alone does not establish Weight coverage.

## Context and Hypothesis

- `Entry condition`: Satisfied for preparation: C1 is frozen and retained collection/placement findings identify phase-accounting pressure. New measurements have not begun.
- `Hypothesis`: A complete production phase partition can cover every physical operation once, while preserving useful-only Trigger charges, prepaid Pipeline control and pay-as-attempted effect-only Action fees.
- `Materiality`: Publish a complete matrix with phase/branch, semantic owner, physical storage owner, maximum Weight method, actual Weight selector, monetary fee owner, caller and exact evidence identity. Every production call path maps to one charged owner; reservations dominate valid actuals component-wise; cross-phase shared work is included exactly once.
- `Dependency boundary`: Acceptance of numeric production coverage additionally consumes EXP-0029 reachable-domain evidence; phase ownership can be established independently. EXP-0031 supplies heap costs without becoming a second phase owner.

## Benchmark Class, Workloads, and Criteria

- `Smallest falsifier`: Trace one nonzero User Action collection across Opening, Running and Suspended on the same legal Task and compare maximum reservation with actual settlement. A missing collection read/write or duplicate base charge rejects that owner assignment.
- `Evidence class`: Call-path ownership audit, legal native witnesses and production-Wasm FRAME branch evidence.

| Phase family | Required branch partition | Deciding witness |
| --- | --- | --- |
| Trigger readiness | All six families, useful/redundant, collection success/failure, detector rearm | One useful transition charge, no paid redundant occurrence |
| Pipeline Opening | Zero/nonzero Steps, User/System, solvent/insolvent, captured Opening state | Complete prepaid machine boundary, no effect surcharge |
| Action attempt | Opening/Running/Suspended; success/skip/permanent/Temporary; StopCycle | Collection Control versus effect Weight and monetary fee |
| Source/successor | Ready consume, Unsignaled/Ready/Waiting destination, capacity fallback | One physical publication owner and correct actual selector |
| Temporal/lifecycle | Cadenced rearm, reference replacement, terminal/close/cancel, cleanup | No omitted or double-counted heap, state-hold or lifecycle work |

- `Acceptance criteria`: Publish a complete matrix with phase/branch, semantic owner, physical storage owner, maximum Weight method, actual Weight selector, monetary fee owner, caller and exact evidence identity. Every production call path maps to one charged owner; reservations dominate valid actuals component-wise; cross-phase shared work is included exactly once.
- `Rejection criteria`: Any uncovered branch, double charge, mismatched actual selector or collection-funded base undercount; classification by Task name alone is insufficient.

## Measurements

No new measurement. The necessary starting facts and remaining evidence boundary are:

The retained baseline gives nonzero User Action collection an explicit Control owner while economic Action fees remain effect-only. UserPaged Opening owns Pipeline collection but skips the Action; those collection phases cannot be conflated. Run progress/suspend fixtures also register references through `write_run_state`, so heap work cannot simply be added again. The phase matrix must still reconcile invocation events, User holds and complete generated envelopes. Source owner: the baseline runtime control provider, Actors scheduler and benchmark call paths identified in Baseline and Candidates; no standalone partial Weight fragment establishes acceptance.
