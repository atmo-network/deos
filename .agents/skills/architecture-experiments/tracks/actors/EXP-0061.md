## Context and Hypothesis

The source qualification rejects treating independent SCALE maxima as an admitted control cell. ActorControlCell contains fixed identity/hot fields, one admission certificate and one Step resource envelope; Contract tails are external. The certificate carries five hashes, two versions, one host-authority lifecycle Weight and PhantomData, not a resource vector. Its lifecycle Weight is fixed by RuntimeAdmissionCertificateAuthority for this binding, independent of authored Contract length. The remaining hypothesis is that a public lifecycle history attains the largest jointly legal temporal/options shape at the required compact resource widths.

## Baseline and Candidates

Retain the current frozen C1 implementation. Compare the nominal type encoding domain with ordinary admitted temporal lifecycle states on the same reference host. This is a reachability certificate, not a candidate storage change or a CPU benchmark.

## Controls

Reference AccountId32 and u32 BlockNumber; existing runtime limits, generated Weight and admission authority; unchanged genesis Actors. Use public creation/replacement, certified funding, real Trigger service and actual Temporary failure. No injected cell, pointer, latch, Run, resource value or admission bypass may support reachability. Mock results qualify only their own host. Read SCALE lengths directly from stored cells and their fields; source constants alone are not an attained-state witness.

## Derived Metrics

The candidate 334-byte upper bound is `8 ActorId + 54 identity + 66 hot + 4 cursor + 5 eligibility + 178 certificate + 19 resources`. System identity is the longest class; the User owner-slot alternative is shorter. The certificate is fixed by the reference admission authority, not authored length.

| Joint-state partition | Bound argument |
| --- | --- |
| Cadenced | Initialized Trigger state is 10 bytes; Block process pointer is 18 bytes including Option, Tick reference is 21; temporal terminal marker is None; last-cycle and eligibility may both be Some. Hot reaches 66 bytes. |
| Non-temporal | Crossing state is at most 10 bytes, no Tick reference is legal, and a window adds only 4 terminal bytes. Even allowing every remaining option gives hot at most 50 bytes. |
| AtTime before Opening | Creation is Idle; replacement cancels the old Run. An unlatched Tick owner has no process placement or eligibility. A latched occurrence disables its Tick reference. The extra consumed byte therefore cannot coexist with both longest pointers. |
| AtTime after Opening | The shared Opening transition sets consumed, including retained-latch replacement; consumed AtTime has no Tick reference. Running/Suspended cannot recover the extra 20 bytes. |
| Non-StopCycle resources | `derive_step_resource_envelopes` fixes head funding count to MaxFundingTrackedAssets and tail counts to zero. `step_control_weight_context` reduces nonzero cursor identity to fragment size; the reference maximum provider depends only on that distinction. The finite overapproximation covers those contexts and all effect choices, retaining only component-wise admissible sums; maximum width is 19. |
| StopCycle/zero-Step resources | Effect is zero (2 bytes); admitted control is component-wise below service, whose encoding is 10 bytes. This partition is at most 12 bytes and cannot enlarge the 19-byte resource ceiling. |

Pointer slot types, window prohibition, current compact widths and complete public lifecycle transitions are load-bearing premises. Neither nominal type maxima nor a rejected wide constructor substitutes for these premises.

## Result

An ordinary reference-Wasm Cadenced retry state attains 334 bytes. A candidate wider Contract with one SplitTransfer(8)/four Current predicates plus eleven StopCycle/four Opening predicate tails passes the mock host but fails ordinary reference-Wasm creation with `ContractStepsExceedOnIdleBudget`. Its benchmark source hash is `c1d5edaf617b2d964785b188d3aba84dd0c326db650b8bae1663502b01e1fdaa`, Wasm hash `40ca8626245cb74406835f6fed6d129cd054289b35ce23b19222f5b1efc29282`, refusal-log hash `e4121f4732fe09812ccb21cd19c146dccd6d09df3dad01a12c85e45eb10714cb`. The refused constructor is removed; no admission bypass or shortened substitute is accepted.

A public Manual latch followed by AtTime replacement and Opening exposed an implementation defect: Opening left `consumed = false` with no latch or deadline. Specification §4.3 preserves the latch and §4.5 requires consumed AtTime after Opening. The shared Opening owner now enforces that flag. Public zero-Step, one-Step and Running User regressions pass; the former busy-AtTime test was a test defect because it fabricated pre-deadline activation through a private helper. Its replacement proves no second Trigger fee or deferred latch after public replacement and Opening.

Validation on the corrected source: complete all-feature Actors package tests pass (1,101 passed, five ignored), the exact runtime resource-domain assertion passes, and workspace/all-feature Clippy passes with warnings denied. Commands use `./scripts/ci-local.sh --only tests --all-features --package pallet-deos-actors`, `--only tests --default-features --package deos-runtime --test-filter encoded_control_resource_boundary`, and `--only clippy`. Scheduler source SHA-256 is `bdedd82571a229f3609194547c6256d8ca454055640e407c2c9af03d2245fbd1`; runtime diagnostic source is `85efb7ede02aec1112ca4e1bb6a6be1e1e5ba1897a340272b760431c6f5ea3d3`, final diagnostic log `0537ec11a4fbf0fbe6094ff8ee8fc20b6a1b2bcb02501c3f8747ec288410cfcd`.

The original Wasm witnesses are reused by scoped semantic equivalence: Cadenced Opening is unchanged, naturally fired AtTime already had `consumed = true` before Opening, and the measured replacement had no retained latch. The correction changes only the previously unqualified retained-latch case; it changes no encoded field, runtime limit, admission envelope or generated Weight. This reuse does not claim a newly built production Wasm. The aggregate quick assurance route still stops at stale fee-vector binding, and benchmark annotation freshness remains an existing G5 obligation.
