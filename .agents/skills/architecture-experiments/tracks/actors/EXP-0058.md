## Decision Question

Do scheduler discovery, Ready source consumption and destination publication compose with exactly one charged physical transition owner for every non-apoptosis service path, without adding generic work to a complete inclusive owner?

## Context and Hypothesis

The canonical service path has four accounting boundaries: one bounded FIFO discovery scan, one loaded Actor-state probe, one Ready source consumption, and one inner transition that publishes exactly one Queue, Waiting or Unsignaled destination or consumes authority in a terminal atom. Direct inner benchmarks intentionally begin after Ready source consumption. The generic Queue destination coefficient must therefore begin from consumed authority; the generic Ready source coefficient must reuse the state already loaded by the actor probe.

Inspection falsified the old primitive fixtures. `scheduler_paged_append_*` started from a retained Unsignaled primary and therefore included source detachment plus Contract/Funding/Run reads. `scheduler_paged_consume_*` called the discover-canonical helper and reloaded the same service state already owned by `scheduler_actor_state_probe`. The benchmark-only fixtures now call the production consumed-authority seams directly; production execution and storage semantics are unchanged.

The first complete-owner falsifier was the admission-close path: `live_queue_head` consumed generic discovery before classification, `service_live_queue_entry` consumed the state probe, and `service_admitted_close` added generic Ready consumption to its close coefficient. `ProvisionalEntryAccounting` now snapshots both meters before one live entry. Admission and settlement for `AdmissionDecision::Close` evaluate from that baseline and replace the entry's discovery/probe/source prefix with exactly one complete apoptosis or terminal-close owner. Earlier tombstone work and a later next-head/empty probe remain distinct operations.

The second falsifier was Crossing unavailability. Zero-Step admission now checks current Crossing availability only after terminal and User Pipeline-capacity precedence. `Unavailable` selects typed `CompleteEntryOwner::CrossingUnavailable`; settlement restores the same per-entry baseline and charges only the complete full-FIFO refusal owner. `Available` carries the observed value/revision into transactional rearm, avoiding a second provider read; `Uninitialized` remains an invariant outside the reference domain. The benchmark is now a production `WeightInfo` surface for EXP-0065 regeneration, while the retained generated file uses the existing conservative Opening fallback rather than a manually copied coefficient.

The placement audit rejected two apparent service transitions. A successful pause atom already clears `queue_ticket` and demotes the Ready primary to Unsignaled transactionally, leaving only an ordinary stale FIFO tombstone; a simultaneously live paused Ready cell is malformed state, not a production Weight branch. Global-breaker classification is now a state-preserving refusal: the exact Ready primary, ticket and queue counters remain unchanged after the metered discovery/state probe, rather than consuming and republishing the same authority under an unmeasured destination owner.

Final Waiting overlap reconciliation separates owner selection from numeric-envelope acceptance. A consumed Ready source followed by an unmatched Wakeup placement selects one complete EXP-0055 publication owner; exact Running/Suspended successor and temporal profiles that already publish Waiting remain inclusive and receive no second publication charge. A due Waiting worker owns its own source removal and Ready publication. Terminal/public close selects one complete EXP-0056 populated-removal atom instead of EXP-0042 plus generic source, close or heap work. EXP-0055's pending maximal-cell requalification can change the selected value, but not this sole-owner partition.

## Interpretation

Nonterminal service composes one discovery, one actor probe, one generic source owner and one exact destination-bearing successor owner. Admission-time apoptosis, terminal close and Crossing-unavailable refusal use the distinct replacement path: the complete entry owner settles from the saved per-entry baseline while unrelated prior/later FIFO work remains charged. The typed refusal selector preserves terminal and insolvency precedence and avoids aggregate subtraction. Paused entries reduce to stale-slot discovery because pause already owns Unsignaled publication; breaker refusal preserves the live Ready source and therefore selects no source or destination transition owner. Waiting publication is either already inside that exact successor/direct profile or selected once as the unmatched destination; populated removal similarly replaces narrower complete-close alternatives. Numeric requalification changes a selected Weight, not the physical partition.

## Decision

Accepted for the admitted reference ownership domain. Select one loaded Ready source owner and one exact successor/placement owner for generic nonterminal service; use per-entry replacement for complete refusal/terminal owners. Waiting publication is inclusive when already measured by an exact successor or direct profile and otherwise selects exactly one EXP-0055 owner. Populated terminal removal selects exactly one EXP-0056 complete close owner. Reject retained-primary/discover-canonical fixtures, live paused service, cross-boundary `write_run_state` profiles and every additive close/Waiting/heap reconstruction. Accepted EXP-0063 supplies numeric envelopes and EXP-0065 owns regeneration.
