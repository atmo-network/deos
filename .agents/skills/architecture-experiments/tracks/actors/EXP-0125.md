## Decision Question

What is the smallest concrete bounded carrier that realizes exactly one Live, Sleeping, Parked, or Pending residence, preserves cyclic encounter order, supports direct arbitrary removal, covers deadlines and reviews, and never copies mutable process authority into membership?

## Governing Specification

- `Exact section`: `BACKLOG.md` N3.5; `template/pallets/actors/docs/specification.en.md` §2.3.
- `Invariant`: One stable Actor-generation process owns semantics; compact generation-bound references own physical membership; every successful or refused transition preserves exactly one obligation and all control operations are bounded.
- `Reopen trigger`: A required transition needs population/predecessor scanning, common Live progress allocates a new membership, a legal deadline is uncovered, or generation reuse can alias an old reference.

## Context and Hypothesis

- `Current architecture`: Ready is a monotonic-ticket C32 tombstone queue carrying whole control cells. Waiting is deadline-keyed C32 pages plus a paged binary min-heap; arbitrary primary removal uses a locator but rewrites the containing whole-cell page and empty-page links.
- `Reason`: EXP-0120 selected stable process plus compact references; EXP-0121–EXP-0124 froze discovery, residence, parking, and negative-work semantics. N3.5 must now bind one physical shape before round and interleaving implementation.
- `Hypothesis`: One actor-keyed intrusive doubly linked cyclic ring for serviceable Live/Pending references, one deadline directory with C32 slot pages and the retained paged min-heap, process-owned Park certificates, and exact reverse handles satisfy every route. No second carrier is needed.
- `Materiality`: Freeze fields, authorities, bounded operations, and structural byte/write counts. Runtime code, generated Weight/ProofSize, round algorithms, callback interleavings, and saturation behavior remain N3.6–N3.8/N5.2.

### Selected Physical Layout

| Owner | Selected value | Authority and bound |
| --- | --- | --- |
| `ActorProcesses[ActorId]` | Stable process with `generation: u64`, semantic state, one `ResidenceHandle`, round/Q1 fields, fee authority, Park certificate or sleep deadline | Sole mutable semantic owner; one value per active generation |
| `ServiceHeader` | `cursor: Option<ActorRef>`, `count: u32` | Sole cyclic encounter frontier/occupancy owner; N3.6 adds no enumerated snapshot |
| `ServiceNodes[ActorId]` | `generation: u64`, `previous: ActorRef`, `next: ActorRef`, `kind: LiveOrPending`, `eligible_round` | One node only for serviceable Live or Pending; actor key plus generation rejects stale alias |
| `DeadlinePages[(WakeupKey,page)]` | C32 `Option<ActorRef>` slots plus `live_entries`, scan slot, previous/next page ids | Sleeping eligibility and Park timed review use the same deadline substrate; direct handle names key/page/slot |
| `DeadlineDirectory[WakeupKey]` | occupancy, head/tail page and heap index | One entry per nonempty deadline key; exact arbitrary bucket close |
| `WakeupCursorPages[(clock,page)]` | Retained C32 paged min-heap of distinct keys | Bounded `O(log MaxActiveActors)` earliest-key insertion/removal; no deadline-range scan |
| Park dependency indexes | Existing/bounded source-specific pages of `ActorRef` plus reverse handles | Only proved closed sources use event invalidation; generic balance/spendability Park also owns one timed-review deadline |

`ActorRef = (actor_id: u64, generation: u64)` is 16 fixed SCALE bytes. A ring node's fixed reference payload is 41 bytes before the concrete round-number width (`generation` 8 + previous 16 + next 16 + one-byte kind); `ActorId` is the storage key and is not duplicated in the value. A deadline slot is `Option<ActorRef>` with a 17-byte maximum. A full C32 slot vector is therefore 544 bytes plus bounded-vector prefix and page metadata; an empty/fragmented page has the same bounded decode ceiling, while mutation touches only that one page. These are structural encoded-value measures, not trie-proof or production Weight claims.

### Mutation and Coverage Matrix

| Transition | Bounded mutation plan | Refusal/rollback authority |
| --- | --- | --- |
| Empty/singleton insert | Create self-linked node; set cursor/count | Prevalidate capacity/generation; source remains unchanged on refusal |
| Multi-member insert/reentry | Insert immediately before current cursor, patch predecessor/cursor neighbor, increment count | Destination node and count admitted before source release |
| Retained Live turn | Update process/Q1 and move cursor to stored next | No node allocation, deletion, or successor ticket |
| Head/cursor/tail/interior unlink | Load target's previous/next, patch at most two nodes, move cursor iff target, delete target, decrement count | Exact reverse node and generation; transaction rollback preserves source |
| Live/Pending → Sleep | Reserve deadline slot/directory/heap path, unlink service node, commit process handle | Destination-first plan or transactional commit; no absent interval |
| Sleep/review due → Pending | Validate exact slot and generation, reserve service node, remove slot/possibly key, commit Pending | Full destination retains source deadline; duplicates only update coalesced process revision |
| Negative Pending → Park | Commit certificate and dependency/review handles, then unlink Pending node | Incomplete registration retains Pending; no uncertified Park |
| Park invalidation → Pending | Secure User fee/System allocation and service capacity, commit newer revision and node, then acknowledge exact source revision | Capacity/refusal leaves Park plus durable unacknowledged invalidation |
| Disable/retire/owner mutation | Revoke generation/process execution first; unlink exact node/slot/index by handles; hand leftovers to bounded cleanup | Old generation cannot target replacement; mandatory cleanup owner remains N4.2 |

Holes never change logical order because the ring is actor-keyed rather than array-position ordered. Ring “wrap” is the explicit last-to-first link, not integer rollover. Full service occupancy rejects a new residence before releasing its source; retained Live progress needs no capacity. Deadline-page holes are bounded to 32 slots and reclaimed when page occupancy reaches zero. Deadline key/order coverage remains complete over both Block and Tick domains because the retained min-heap indexes every nonempty key, including clustered and already-overdue keys.

## Result

Candidate A covers every selected state with one stable semantic owner and at most one service/deadline residence. The doubly linked actor-keyed ring supplies direct arbitrary unlink without predecessor discovery and keeps ordinary Live progress resident. The retained paged deadline heap already supplies bounded Block/Tick ordering; changing its payload from whole cells to 16-byte generation references removes the reason to invent a second temporal carrier. Park is process evidence plus bounded invalidation/review handles, not another queue.

## Interpretation

A “ring” need not be a dense page or monotonic ticket namespace. Actor-keyed intrusive links make supported occupancy, not historical Actor IDs or ticket span, the physical bound. The cost is up to two neighbor-node writes on structural movement, accepted because it buys direct removal and stable encounter order. Deadline pages remain appropriate because temporal order is key order rather than cyclic service order; forcing both into one representation would add accidental machinery.

## Decision

Accept Candidate A as the sole N3.5 carrier: stable Actor-generation process records; one intrusive doubly linked service ring for Live/Pending; one retained C32 deadline-page plus paged-min-heap substrate for Sleep and Park reviews; process-owned Park certificates and bounded source indexes; and exact generation-bound reverse handles for every membership. Do not compare or implement a second carrier unless implementation falsifies a stated bound.

## Rejected Alternatives and Tradeoffs

| Candidate | Decision | Evidence-backed reason |
| --- | --- | --- |
| Singly linked service ring | Rejected | Arbitrary owner/protocol removal lacks bounded predecessor authority |
| Paged dense ring with slot-order traversal | Rejected initially | Adds hole/compaction/order machinery without a demonstrated advantage over actor-keyed links |
| Keep monotonic Ready ticket tombstones | Rejected as target | Common Live continuation allocates successors and ticket span diverges from occupancy |
| Separate Pending FIFO | Rejected | Duplicates fairness/residence machinery; Pending and Live share the service encounter carrier with typed node kind |
| One carrier for ring and deadlines | Rejected | Cyclic encounter order and minimum temporal order require different operations |
| Event-only generic-balance Park | Rejected | Mutation domain is not proved closed; timed review remains mandatory |
| Bitmap/dense ActorId carrier | Rejected | Allocation follows historical identity range rather than active occupancy |

## Validity

- `Establishes`: One concrete carrier, exact owners/handles, direct arbitrary-removal authority, hole/wrap/full rules, generation binding, occupancy authority, and deadline/review coverage.
- `Does not establish`: Implemented correctness, exact stable-process bytes, numeric Weight/ProofSize, round-frontier behavior, callback interleavings, saturation throughput, or release viability.
- `Known limitations`: Layout is not yet runtime storage; full/fragmented measurements are structural value/write bounds, not generated benchmark samples.
- `Invalidation triggers`: Any implementation path needs unbounded scan, duplicate residence, unreserved destination, generation alias, uncovered deadline, or common Live allocation.
- `Residual qualitative insight`: Service order and time order deserve distinct minimal carriers, while semantic state belongs in neither.
