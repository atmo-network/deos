## Decision Question

Does the qualified funded User path have a complete, disjoint Pipeline/Action resource mapping?

## Governing Specification

- `Exact section`: `template/pallets/actors/docs/specification.en.md` §§3.4, 7.3–7.6 owns fee/control boundaries; `docs/actors-resource-policy.specification.en.md` §§1, 4 owns resource domains and admission/actual Weight. BACKLOG owns open G4/G6 gates.
- `Invariant`: Pipeline authority and pay-as-attempted Action fees remain separate; complete-owner settlement cannot borrow another owner's charge.
- `Reopen trigger`: A required semantic fee change must reopen specification, not become a resource optimization.

## Context and Hypothesis

- `Reason`: G6 funded User accounting remains open after the G4 selector gap.
- `Hypothesis`: Qualified production bindings can map every executed funded User charge exactly once.
- `Materiality`: A missing, duplicated or misattributed charge changes resource soundness.

## Measurements

`full_executive_funded_pipeline_collection_witness` passes through the canonical runtime test route. The User StopCycle row charges Trigger fee `10,351,120` and Pipeline fee `96,179,991`; the System row charges neither. Both settle `13,614,382,122 / 141,953` Control, `12,650,082,748 / 135,722` in Prepass and zero effect. Sovereign and Fee Sink balance deltas equal each typed fee exactly once, and no `ActionFeeCharged` event occurs because StopCycle invokes no Action.

`full_executive_user_completion_header_domain_witness` also passes. OwnerOnly and maximum SignedAllowlist heads differ in encoded bytes (`157/1` versus `670/514`) but share source-derived completion context `[0,1,0,0,0,0,40]`, stored Control `2,898,615,858 / 33,863` and block Control `13,614,382,122 / 141,953`. This supports context-domain aliasing only; encoded-byte growth is not proof growth.

These are native full-Executive monetary/state witnesses. They do not execute EXP-0095 Wasm and do not cover attempted Action collection.
