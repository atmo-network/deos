The maximum-head User witness closes this Leaf because the claimed Manual domain is attained; temporal/Crossing rearm, close, source/Waiting geometry and variable nonzero-Pipeline holds are separately owned and do not require inflating or reopening this base owner.

## Decision

Accepted for the reference Manual binding. System selects the complete System zero-Step owner; User selects the complete maximum-head owner at `167,832,000` RefTime / `9,047` ProofSize plus 11 reads and 5 writes.
