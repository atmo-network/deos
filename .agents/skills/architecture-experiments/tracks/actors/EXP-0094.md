## Decision Question

Does a complete consumed-source User completion owner cover the reachable cross-product of maximum `SignedAllowlist` header width and positive Contract tails, without adding separately measured overlapping envelopes?

## Governing Specification

- `Semantics`: `template/pallets/actors/docs/specification.en.md` §§3.1, 3.4–3.5, 7.3–7.7.
- `Resource ownership`: `docs/actors-resource-policy.specification.en.md` §§1, 4–6 requires complete component-wise admission and actual settlement.
- `Invariant`: Preserve C1, FIFO, cutoff, Q1, causal floor, custody, Pipeline/Action separation, funding-only hold release and committed-Step durability.
- `Reopen trigger`: A semantic change belongs to specification; this Leaf may qualify only physical coverage.

## Context and Hypothesis

EXP-0068 accepts positive-tail completion for its attained minimal FundingSourcePolicy head. EXP-0069 accepts maximum-header completion only at zero tails. Both dimensions are simultaneously reachable, so selecting their component-wise maximum would be an unsupported aggregate unless one owner is shown to cover the cross-product.

The hypothesis is that one source-owned maximum-header positive-tail benchmark over `t=1..=3` can cover the combined branch. This is a new reachable-state domain and therefore cannot be inferred or measured in either predecessor.

## Result

Measured and interpreted. T/T16 complete on one fresh Wasm; T16 retains the same generated I/O shape, adds the exact 513-byte policy proof at every tail count and dominates T in both Weight dimensions. Production artifacts remain unchanged.

## Interpretation

Neither predecessor was wrong; each remains Accepted within its axis. T16 supplies the missing simultaneous-path owner. The exact repeated 513-byte delta supports funding-policy-width attribution in this bounded domain, not arbitrary Contract-head fields. Existing scalar tail context can select T16 without a new public dimension.

## Decision

Accepted for reference `MaxWhitelistSize = 16` and positive tails `t=1..=3`. Select T16's generated model as the complete combined-path input to EXP-0067. Do not install it until live selector composition proves non-overlap and maximum/actual containment.
