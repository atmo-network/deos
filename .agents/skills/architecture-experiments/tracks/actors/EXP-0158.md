## Decision Question

Does the selected scalar skip work unit fit its currently charged `WeightInfo::crossing_skip_unit` fallback default of `500,000,000 / 180,000` in both dimensions on the corrected benchmark runtime Wasm? This scalar owner becomes the conditional ProofSize family-minimum branch after the two pair defaults investigated in EXP-0157; neither result alone selects production Weight.

## Governing Specification

- `Exact section`: `docs/actors-resource-policy.specification.en.md` §§2–4; `template/pallets/actors/docs/specification.en.md` Crossing materialization and source authority.
- `Invariant`: Every reachable scalar skip and its physical work fit the admitted Actor Control branch in both dimensions; semantic causality, cursor and rollback do not weaken to improve throughput.
- `Reopen trigger`: A complete owner cannot fit normative one-third Control plus mandatory Deadline/Service without a deliberate evidenced architectural decision.

## Context and Hypothesis

- `Current architecture`: `crossing_plan_weight(SkipPostInstallationTransition)` selects the inherited scalar default because `crossing_skip_unit` is extra-only, absent from the runtime-generated implementation. `do_crossing_work_unit` loads the Actor and skips when installed revision is at least the transition revision; a one-member page makes scalar service reachable. EXP-0157 showed the default pair unit underbounds a selected RefTime path and that the scalar `180,000` ProofSize default becomes the component-wise family-minimum maximum *only in a counterfactual* that replaces both pair defaults.
- `Reason`: The scalar owner is an independently charged fallback and cannot inherit physical bounds from the pair's distinct unit. Its extra fixture previously invoked an obsolete frame-primary alignment on a canonical Unsignaled Actor; that setup has been removed and the package test passes.
- `Hypothesis`: A selected scalar skip RefTime estimate exceeds its charged `500,000,000` RefTime default. ProofSize is compared independently; no maximum claim follows from one ordinary-header Actor.
- `Materiality`: A direct selected RefTime underbound gates coordinated generation and narrows the finite Crossing selector inventory without a class×header×feed benchmark matrix.

## Derived Metrics

- `RefTime`: `111,259,000 + 18 × 25,000,000 + 2 × 100,000,000 = 761,259,000`, exceeding the inherited scalar price by **261,259,000 ps**, or 52.25% of that price. This benchmark wraps the **direct `do_crossing_work_unit`**, not the coordinator base or work probe, so no subtraction is valid or needed.
- `ProofSize`: selected estimated `11,729`, below the default reservation by `168,271`; this selected value is not an upper for all legal source pages or headers.
- `Fixture falsifier`: A first rebuilt Wasm run with only obsolete primary alignment removed measured `250,036,000 + 50 reads + 2 writes = 1,700,036,000 / 81,886`, but a later pre-block `classify_crossing_work()` assertion showed **OpenLeaf**, not scalar skip (Wasm `6584f32e2b7a103f74ec7a9de1406e25582b91a957848c1b637445a36ec0849e`). That earlier result is *invalid* as skip evidence. The failure showed the missing cursor position, so the fixture now explicitly positions its existing leaf, asserts `SkipPostInstallationTransition`, and rebuilds the Wasm. The pre-block assertion excludes fixture classification work from the timed block.

## Statistical / Variance Notes

The initial package benchmark passed while measuring OpenLeaf: post-state assertions alone did not identify the timed path. The explicit pre-block classification assertion failed on the first rebuilt Wasm and passed after cursor positioning; the final direct skip result is selected and cannot certify all legal Actor header widths, full page occupancy or fault paths.

## Result

The exact selected scalar skip exceeds its charged RefTime default. The original extra fixture assumed a nonexistent primary **and had not advanced the cursor to the existing leaf**; the latter caused an OpenLeaf measurement until the pre-block selector assertion exposed it. Production Crossing logic remains unchanged.

## Interpretation

Both scalar and pair skip defaults now have selected direct RefTime underbounds (this record and EXP-0157). The scalar default's large ProofSize reserve still contributes to the conditional family minimum after any certified pair replacement, but the `11,729` selected scalar proof cannot replace `180,000` without a complete owner.

## Decision

Reject the charged `crossing_skip_unit` RefTime default for the selected scalar skip. Retain default as production reserve only until complete conservative branch owners and admission are coordinated; do not silently treat undercharge as safe. No production Weight/Wasm rebind authorized.
