## Decision Question

Can the selected four-leg healthy maximum-header User-recipient effect witness cover one inline `WindowExpired` recipient close, without a separate Task charge?

## Governing Specification

- `Exact section`: `template/pallets/actors/docs/specification.en.md` §9.2 and `docs/actors.integration.en.md` certified ingress.
- `Invariant`: Certified ingress may substitute `WindowExpired` close; the invoking Task owns the complete synchronous effect. `TmctolTaskEffectWeight` admits and settles one `task_split_transfer(legs.len())` maximum regardless of recipient state.
- `Reopen trigger`: The terminal branch becomes unreachable in any admitted SplitTransfer or a matched accepted physical upper bound dominates it in both dimensions.

## Context and Hypothesis

- `Current architecture`: The mandatory Prepass itself admits Service. `four_leg_split_transfer_closes_expired_recipient_during_prepass_service` observes at least one same-window User recipient close after its own ledger transfer in a real four-leg sender Task; this is not four proven inline closes.
- `Reason`: EXP-0150 measured four healthy maximum-header User recipients but excluded terminal ingress.
- `Hypothesis`: The selected EXP-0150 healthy User effect estimate also contains one maximum-header User recipient that closes inline on certified ingress.
- `Materiality`: A matched terminal witness exceeding the healthy estimate in either dimension rejects domination; a selected witness is not a universal maximum or production coefficient.

## Result

Both benchmark shapes execute. E finalizes the expired recipient inside the measured transfer loop, while the remaining healthy recipients admit certified ingress. E exceeds H by +999 estimated ProofSize and +4,372,801,000 ps including reference DB costs.

## Interpretation

The small ProofSize delta is not a per-close bound: repeated keys/proof geometry and the missing healthy Trigger work affect the comparison. The runtime regression separately establishes that an admitted sender Task can encounter an expired recipient; the benchmark measures the direct adapter branch with stronger User headers, not that exact scheduler interleaving.

## Decision

Status Rejected: the selected H-domination hypothesis fails. Outcome class: research result. No production Weight is adopted; stop after one matched contrast. A complete four-leg Task-effect bound must account for inline terminal cleanup while preserving two-dimensional Actor-base and Service admission.
