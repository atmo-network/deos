## Decision Question

Do the regenerated Actors Weight, production Wasm, metadata and all exact-identity consumers converge after EXP-0067's User completion selector correction?

## Governing Specification

- `Owners`: `docs/actors-resource-policy.specification.en.md`, `docs/actors-performance-assurance.specification.en.md`, pallet specification and project production-Weight/runtime validation contracts.
- `Invariant`: Preserve frozen C1 and semantics; generated artifacts must derive from one source and every consumer must bind the same final identities.
- `Reopen trigger`: Semantic or geometry drift returns to its owner; this Leaf refreshes binding evidence only.

## Context and Hypothesis

EXP-0067 now selects generated maximum-header User completion owners for zero and positive tails. Full Actors generation changed the production Weight, and a production runtime build changed Wasm. EXP-0065's exact old bundle therefore no longer certifies current source. The hypothesis is that affected artifacts and consumers can converge without changing C1 or unrelated semantics.
