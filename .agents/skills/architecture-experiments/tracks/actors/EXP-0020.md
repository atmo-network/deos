## Decision Question

Which bounded detector disable/re-arm topology enforces zero Actor-specific Trigger evaluation, fee, activation, and causal-history accumulation while `pending_signal == true` without taxing dormant Actors or weakening current-state re-arm?

## Governing Specification

- `Exact section`: `template/pallets/actors/docs/specification.en.md` → `1.2 Declarative Trigger Topology`, `1.4 Block-Paced Actor Cycles`, `3.2 Triggers and Timing`, `4.3 State Holds and Fees`, and `7.1 Events`; `docs/actors-performance-assurance.specification.en.md` → `3.5 Minimal User Apoptosis`.
- `Invariant`: Only `pending_signal: false -> true` is a useful Actor-specific Trigger occurrence and charge. While latched, redundant sources do no Actor-specific Trigger evaluation, fee collection, activation, or history accumulation. Opening re-arms from current authoritative state and preserves at most one active plus one deferred Pipeline.
- `Reopen trigger`: Reopen Specification if a family cannot re-arm from current authoritative state without replay, if suppressing latched work would lose source truth required outside Actors, or if one-shot AtTime cannot remain consumed independently of latch clearing.

## Context and Hypothesis

- `Baseline architecture`: The invalidated EXP-0019 baseline kept detector authority active while latched, evaluated repeated family occurrences, charged each successful User occurrence, and reported paid coalescence. Pipeline Machine P0, Action, apoptosis, custody, and zero-Step evidence remains reusable.
- `Reason`: Paid coalescence permits source spam to impose repeated Actor-specific computation and fees while producing no additional readiness or Pipeline.
- `Hypothesis`: Eagerly removing indexed detector memberships on useful latching and reinstalling them from current authoritative state during Opening eliminates latched-period Actor work. Manual and AddressEvent can reject from one hot latch probe because they have no detector membership. A resident generation-disabled membership may reduce re-arm writes only if workers can reject it without Actor-state loading and without increasing source-frontier cost.
- `Materiality`: Acceptance requires zero Actor-specific fee/event/activation for redundant latched sources, no Actor-state load by indexed detector workers for disabled Actors, bounded atomic disable/re-arm, current-state Crossing/cadence behavior, no dormant-population tax, and no regression to inherited P0 Pipeline/Action semantics.

## Statistical / Variance Notes

The complete 50-step/20-repeat model exists under the recorded benchmark Wasm and Weight identities. B0 cannot supply a valid numerical control because its paid-coalescence semantics are rejected. Decision therefore uses generated boundedness plus exact branch traces: A2 retains unavoidable bounded source-entry traversal but replaces latched Actor-state/classification/fee/activation work with one detector-local authority probe and cursor progress. No timing samples were discarded.

## Result

A1 direct-family implementation rejects an already-pending occurrence before capacity, fee collection, activation, and event emission. AddressEvent gates source/asset Trigger filters on an unset latch while preserving independent funding accounting. ObservationChange returns from compact hot-latch state before classification, fee, activation, or event. Eagerly removing its subscription at latch was tested and deleted: four dirty-fanout mutation/restart/model regressions failed because removal mutates or clears the authoritative pass being consumed. Crossing distinguishes an active Pipeline with no deferred readiness from an already-latched deferred Pipeline: the former is useful and charged, while later transitions take detector-local skip without phase/revision, fee, event, or activation. Cadenced detection removes its future tick membership after a useful latch; Opening atomically installs the first deadline after current time before Pipeline charging, and capacity failure rolls back. AtTime remains consumed. The event field is removed and the full pallet suite passes.

## Interpretation

Manual, AddressEvent, ObservationChange, and Cadenced semantic evidence supports the useful latch. Cadenced establishes eager temporal detach plus current-state Opening re-arm with exact rollback, eliminating A2 for temporal topology. ObservationChange eager detach is rejected under the current authoritative dirty-pass topology; A2 now owns membership-local disabled authority that preserves pass structure while avoiding Actor-state loading. Crossing eager removal is likewise rejected because current-page compaction invalidates range cursor and cohort authorities. ObservationChange A2 retains subscription topology but checks one detector-local disabled authority before Actor-state loading, sets it atomically with useful readiness, and clears it before Opening charge. Crossing shares that authority: classification and scalar service skip disabled members before Actor-state loading, latched transitions do not update phase/revision, and Opening atomically relocates membership from current provider state before Pipeline charging.

## Decision

Accept the hybrid A1/A2 topology. Manual and AddressEvent use early direct latch rejection; Cadenced uses eager temporal detach and current-time Opening re-arm; AtTime remains consumed. ObservationChange and ObservationCrossing retain stable physical memberships behind `IndexedTriggerDetectionDisabled`, skip before Actor-state load, and re-enable atomically at Opening. A1 eager removal is rejected for indexed families because it mutates active source traversal.

## Validity

- `Establishes`: Useful-only charging, topology-preserving indexed disablement, authoritative re-arm, complete generated Weight, exact source/Wasm/metadata identity, and deterministic family regressions.
- `Does not establish`: Final release-tree identity, downstream launch readiness, or an empirical wall-clock throughput claim.
- `Known limitations`: Latched indexed identities still incur one detector-local membership probe when their retained source page/range is visited; this is bounded source traversal, not Actor-state evaluation.
- `Invalidation triggers`: Trigger semantics, authoritative Oracle/timestamp ownership, Q1, FIFO, P32, Pipeline Machine strategy, or detector source topology changes.
- `Residual qualitative insight`: Removing useless detector authority at the latch boundary is preferable to repeatedly proving at the Actor body that readiness already exists.

## Follow-Up / Next Gradient
