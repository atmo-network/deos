## Decision Question

What is the smallest mutable frontier over the EXP-0125 cyclic ring that gives every membership eligible at block opening at most one ordered attempt, preserves an unaffordable valid head, defers all same-block admissions and reentries, and terminates after one round without an initial-length counter or removable sentinel?

## Governing Specification

- `Exact section`: `BACKLOG.md` N3.6; `template/pallets/actors/docs/specification.en.md` §1.4 and §2.3.
- `Invariant`: Block `B` is the immutable round identity; strict cyclic encounter order and independent Q1 admit at most one attempt per eligible Actor in `B`; mutations cannot donate or recapture a turn.
- `Reopen trigger`: A legal mutation can erase the only round-closure evidence, an admission can execute in its admission block, a valid refused head can be bypassed, or one round needs an initial population count, sentinel, or repeated scan.

## Context and Hypothesis

- `Selected carrier`: EXP-0125 gives one actor-keyed doubly linked ring, a persistent cursor, generation-bound nodes, and stable process state, but intentionally leaves round transitions open.
- `Hazard`: Capturing initial length miscounts after removal; a start-Actor sentinel can disappear; moving the cursor past an unaffordable head violates FIFO; reinsertion behind the cursor can recapture a turn after wrap.
- `Hypothesis`: Stamp every node with the last block round in which it was considered, stamp every same-block admission/reentry as already considered, and keep `ServiceHeader.cursor` at the next encounter. The first node already stamped `B` is a durable distributed wrap boundary even when any other node is removed.
- `Materiality`: Freeze exact state transitions and proof cases. Runtime code, callback ordering, saturation reserve, and generated Weight remain N3.7/N3.8/N5.2.

## Measurements

### Selected State

| Owner | Field | Rule |
| --- | --- | --- |
| `ServiceHeader` | `round_block`, `cursor`, `count` | `round_block` may initialize/advance once for consensus block B and never reset by Prepass/Drain; `cursor` names the next encounter; `count` owns occupancy only, never round progress |
| `ServiceNodes[ActorId]` | generation, previous, next, kind, `eligible_from`, `last_considered` | Node is attempt-eligible iff generation matches, `eligible_from <= B`, and `last_considered < B`; `last_considered == B` is the distributed closure marker |
| `ActorProcesses[ActorId]` | `last_attempted` plus semantic state | Q1 independently requires `last_attempted < B`; only an admitted attempt sets it to B |

A newly created or reentered node in B receives `eligible_from = B + 1` and `last_considered = B`. This applies to external admission, due/review materialization, generation replacement, and post-attempt reentry. The marker does not claim an attempt occurred; it prevents the new residence from joining the already-open round.

### Service Transition

1. Initialize `round_block = B` only if the stored header belongs to an earlier block; retain the existing cursor.
2. If `cursor` is absent, stop empty. Load its exact generation-bound node.
3. If `node.last_considered == B`, stop: one full cyclic round has reached a B marker. A value greater than B or inconsistent generation is an invariant fault, not ordinary skip.
4. Require `eligible_from <= B`. A correctly admitted future node already has `last_considered == B`; an unmarked future node is an invariant fault.
5. If process Q1 is already B, mark this encounter considered B and advance once without executing. This is bounded defensive convergence, not donated service.
6. Preflight the complete attempt resource envelope before changing marker or cursor. If the valid head is unaffordable, stop with both unchanged.
7. Execute transactionally. On a retained Live/Pending outcome, set node `last_considered = B`, process `last_attempted = B`, and cursor to the captured successor. On removal/Sleep/Park/completion, capture the successor first, unlink directly, commit process outcome, and set cursor to that successor if one remains. On rollback/refusal, preserve the source and frontier exactly.

### Mutation Matrix

| Case | Before | Transition | After / proof |
| --- | --- | --- | --- |
| Empty admission in B | no cursor | self-link, mark B, eligible B + 1 | cursor points to a B marker; zero B service; singleton is first in B + 1 |
| Singleton retained | A unmarked | admit/execute A, mark B, cursor A | immediate marker encounter closes; exactly one attempt |
| Partial A→B→C | cursor B after A | budget stop before B | B remains unmarked and cursor B; B is first next phase/call in B |
| Complete wrap | A/B/C each marked while cursor advances | C advances to A | A's B marker closes without rescanning B/C |
| Insert X then Y before cursor C | C is first unserved | splice X then Y before C; both marked B | encounter order remains C…X,Y next round; neither can run in B |
| Current A reenters | capture successor B, unlink A, splice A before B marked B | cursor B | B and remaining old members retain turns; A stops wrap and starts B + 1 after the old suffix |
| Remove unserved cursor B | cursor B | direct unlink selects stored successor C | cursor C; no predecessor or removed-member turn is donated |
| Remove served/interior A | cursor C; A marked B | direct unlink A | another surviving/new B marker still closes; if none remains, empty or newly admitted nodes are already B-marked |
| Remove last member | singleton removed | cursor None/count 0 | round ends; later B admission is marked and cannot execute |
| Replace generation | old ref revoked/unlinked; new ref inserted | new generation marked B, eligible B + 1 | old marker cannot alias new process; replacement cannot recapture old turn |
| Valid blocked head | cursor B unmarked | full envelope does not fit | no marker/cursor mutation; C cannot bypass B |
| Repeated phase call | round_block already B | no reinitialization | continues at cursor or observes marker; no phase-reset double service |

Each successful consideration changes one process and at most the header plus its own node, with EXP-0125 neighbor writes only when residence changes. A blocked valid head changes none. No path walks an already B-marked prefix: the first B marker terminates immediately.

## Result

Candidate A closes a block round through state already required on each persistent node. Every opening member begins with `last_considered < B`; each committed consideration stamps B; every B admission/reentry starts stamped; therefore the first B marker reached by the persistent cursor proves that no earlier unconsidered opening member remains in cyclic order. Arbitrary removal cannot erase closure globally because surviving considered or newly admitted nodes carry the same marker, while removal of all such nodes leaves either an empty ring or only B-marked admissions.

## Interpretation

The round boundary is a property of each residence, not one fragile member identity. `count` remains pure capacity truth and is not overloaded as progress. `last_attempted` remains process-level Q1 truth and cannot replace encounter bookkeeping because cancellation, replacement, or defensive already-attempted convergence may change residence independently. The cursor moves only after a considered outcome; affordability refusal therefore preserves strict head order.

## Decision

Accept Candidate A: consensus block number is the immutable round identity; `ServiceHeader` owns one persistent cursor but no start sentinel or remaining count; each service node owns `eligible_from` and `last_considered`; process state independently owns `last_attempted`. Stamp all B admissions/reentries as considered and B + 1 eligible. Stop at the first B marker, and never advance a valid unaffordable head.

## Rejected Alternatives and Tradeoffs

| Candidate | Decision | Evidence-backed reason |
| --- | --- | --- |
| Capture initial ring length | Rejected | Removal/replacement changes what the count means and can donate turns or require decrement coordination across every mutation |
| Capture start ActorRef sentinel | Rejected | Owner/protocol removal can erase the only wrap boundary; replacement generation cannot inherit it safely |
| Capture tail/frontier ActorRef | Rejected | Tail removal has the same sentinel hazard and insertion semantics become position-sensitive |
| Per-phase cursor/frontier | Rejected | Prepass/Drain repetition can reset service and violate Q1/order |
| Advance past unaffordable head | Rejected | Creates cost-based bypass and hidden priority |
| Use only process Q1 | Rejected | Does not distinguish same-block admission from an opening member or provide robust wrap closure after residence mutation |
| Move served nodes to a second list | Rejected | Adds carrier/allocation work to ordinary progress and duplicates occupancy authority |

The accepted tradeoff is one block marker write on each retained considered node and two block-valued node fields. N5.2 must measure their concrete cost; semantic closure is not exchanged for a cheaper fragile sentinel.

## Validity

- `Establishes`: Immutable per-block round identity, persistent cursor semantics, distributed closure, insertion/reentry deferral, direct-removal behavior, strict blocked-head retention, generation replacement, and independent Q1.
- `Does not establish`: Runtime correctness, callback/lost-wakeup ordering, saturation reserve, fault quarantine, exact encoded widths, generated Weight/ProofSize, throughput, or release viability.
- `Known limitations`: Defensive Q1 convergence is specified logically but its concrete fault/event treatment remains implementation-owned; no empirical resource claim is made.
- `Invalidation triggers`: Same-block admission executes, an eligible opening member is skipped/duplicated, a valid refusal advances, closure scans a B-marked prefix, or mutation requires a second frontier authority.
- `Residual qualitative insight`: Distributed round markers turn arbitrary member deletion from a frontier-special case into an ordinary bounded unlink.
