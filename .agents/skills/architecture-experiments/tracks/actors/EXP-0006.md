## Decision Question

Does `20/80`, `25/75`, or `30/70` maximize useful Actor progress while retaining explicit user and Actor effect capacity?

## Governing Specification

- `Exact section`: `docs/actors-resource-policy.specification.en.md` → `2. Resource Algebra` and `3. Economic Zipper`.
- `Invariant`: Allocation remains component-wise, work-conserving, class-neutral, and split equally between Actor/User base turns inside Shared Economic.
- `Reopen trigger`: Selecting a candidate that removes guaranteed user service, changes FIFO/Q1, or treats RefTime and ProofSize as fungible requires Specification reopening.

## Context and Hypothesis

- `Current architecture`: Production reserves 20% of schedulable Weight for Actor Control and 80% for Shared Economic, split into equal 40/40 base turns.
- `Reason`: The accepted effectful 10,000-Actor first traversal averages about 7.7 distinct Actors per block and Actor Control binds before cheap Transfer effects.
- `Hypothesis`: 25% or 30% Control materially increases committed Steps without making user or expensive Actor effects the new unacceptable bottleneck.
- `Materiality`: Select a non-baseline candidate only for at least 20% more distinct Actors per saturated block or a Pareto improvement in 10k traversal with explicit retained user throughput.

## Statistical / Variance Notes

Deterministic semantic counters must match exactly. Wall-clock duration is diagnostic only; consensus decisions use generated two-dimensional Weight and fixed workload counters.

## Result

W1, W2, and W3 completed deterministically for A0/A1/A2, and W4 resource algebra passes every candidate. W1 exactly matches W2 at 1,000/867/746 completion blocks, proving that one continuous user dispatch does not mask attribution. A2 finishes W3 228 blocks earlier than A0; all 400 SwapOut Actors reach successful zero-failure dispositions.

## Interpretation

Measurement is complete. W1 and W2 are identical, so the continuous user dispatch is non-binding. A1 misses the predeclared materiality threshold in all measured traversals. A2 yields about 34.0% more W1/W2 throughput and 29.8% more W3 throughput; 400 SwapOut effects do not make 70% Shared Economic binding. The measured cost is explicit: each guaranteed Shared base turn shrinks 12.5% from the A0 value. A2 is the only candidate that clears materiality in every throughput workload while preserving exact user-turn algebra and zero failed mixed effects.

## Decision

Accept A2 as the DEOS reference allocation: 30% Actor Control, 70% Shared Economic, and equal 35% Actor/User base turns. Reject A1 as sub-material. Delete candidate-only feature branches after binding A2 as the fixed production default; retain the generic checked ratio constructor as host/resource-algebra capability.

## Rejected Alternatives and Tradeoffs

| Candidate | Decision | Evidence-backed reason |
| --- | --- | --- |
| A0 20/80 | Rejected | Correct and safe, but materially slower in every saturated traversal |
| A1 25/75 | Rejected | Improves throughput only 14.8–15.4%, below the declared 20% threshold |
| A2 30/70 | Accepted | Improves throughput 29.8–34.0%, preserves continuous user dispatch, zero failed mixed Steps, and exact borrowing |
| Above 30% Control | Excluded | Would reduce each Shared base turn below 35% before nearby candidates establish need |
| Dynamic per-block ratio | Excluded | Adds policy/state complexity and changes the fixed resource contract |

## Validity

- `Establishes`: A2 is the best declared fixed allocation for the measured production workloads.
- `Does not establish`: A universal optimal ratio or execution SLA.
- `Known limitations`: User demand uses one admitted call per block rather than saturating every user base turn; W4 proves the exact guaranteed envelope algebra.
- `Invalidation triggers`: Changed Weight owners, block limits, FIFO/Q1 semantics, workload geometry, or resource algebra.
- `Residual qualitative insight`: Control gains must be priced against both Actor effects and user work.

## Follow-Up / Next Gradient

```text
100 Steps/block aspiration → A0 about 7.7 distinct Actors/block
→ Actor Control appears binding → ratio is the owning policy
→ test 25/75 and 30/70 → optimize authority only if ratio remains insufficient
```

- `Eliminated hypotheses`: A1 is sub-material; A0 is slower; ratios above 30% and dynamic ratios remain unearned.
- `Remaining hypotheses`: Execution-authority geometry can reduce the dominant control unit further under A2.
- `Stop condition`: Met by accepting A2 after W1-W4.
