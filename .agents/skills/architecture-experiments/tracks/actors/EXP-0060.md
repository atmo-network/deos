## Decision Question

Does the current control/effect settlement boundary return only actual Weight component-wise contained by its matching reservation, with zero Task-effect Weight for `NotInvoked`?

- `Frozen physical input`: [EXP-0025](./EXP-0025.md) C1 Architecture Freeze. No change to FIFO, ticket chronology, Q1, causal floor, primary/reference ontology, source/successor atomicity or sole execution owner.
- `Semantic oracle`: A0 SHA-256 `8746e423168309975e509be91e4eb06fdf0eb0b43369d75f1ee62202a4341678` remains frozen; use only for relevant semantic equivalence, never as a Weight oracle.

## Context and Hypothesis

The phase-specific numeric owners are decided by the other EXP-0028 children. This Leaf decides only their common post-dispatch trust boundary: the runtime effect provider must be total over the configured `Task` shapes, `NotInvoked` must select zero, every returned Control actual must fit the supplied matching maximum, and the resource ledger must reject an overrun atomically. A numeric underbound in an owning child remains that child’s or EXP-0065’s artifact problem; it is not hidden by this settlement proof.

## Baseline and Candidates

The retained candidate is the existing typed selector chain: `TaskEffectWeightProvider` maps `NotInvoked` to zero and `Invoked` to the same family method as maximum admission; `RuntimeStepControlWeight` returns a Control actual only after a component-wise comparison with the supplied maximum; scheduler call sites independently reject missing or excessive evidence; and `BlockResourceUsage::settle` performs the final reservation check. The rejected alternative is accepting absent or over-reservation evidence and relying on incidental budget margin.

## Controls

Source semantics, configured bounds, generated Weight inputs, host adapters and resource partition remain unchanged. The audit varies only the typed execution branch or one resource component. Native rollback witnesses use the same admitted one-Step Transfer and add exactly one unit to either RefTime or ProofSize. No benchmark body, production Weight or runtime behavior changes.

## Benchmark Class, Workloads, and Criteria

This is deterministic selector and transaction-boundary evidence rather than timing measurement. Acceptance requires all configured Task-family shapes to map `NotInvoked → 0` and `Invoked → matching maximum`; every successful Control actual and resource settlement to satisfy `actual.all_lte(maximum)`; and independent one-unit RefTime/ProofSize overruns in either Control or effect to roll back the complete attempt without authority, event, custody or recipient mutation.

## Result

The production effect provider is exhaustive over the current `Task` enum and SplitTransfer bound. Its two branches are definitionally contained: zero or the matching maximum. `RuntimeStepControlWeight::actual_control_weight` validates the supplied Opening maximum where required, rejects inconsistent collection evidence, and exposes an actual only through `actual.all_lte(maximum).then_some(actual)`. All scheduler execution paths independently compare provider output with the reserved value before fee collection and commit evidence. The resource ledger repeats the same component-wise check, and pair settlement restores both lanes if either lane fails.

The new finite provider assertions and two-dimensional one-unit transaction witnesses pass. Existing exhaustive settlement-grid and phase-selector regressions also pass. No numeric owner, generated coefficient, fee rule or runtime transition changed.

## Interpretation

Containment does not depend on spare RefTime, spare ProofSize or an aggregate allowance. `NotInvoked` releases the entire effect reservation, while `Invoked` cannot select a different or larger family method than admission. A missing, malformed or over-reservation Control/effect actual fails closed before the attempt can retain semantic, fee or FIFO mutation. Therefore the common settlement boundary is sufficient for the admitted current provider domain; numeric soundness and exact artifact identity remain with their declared downstream owners.

## Decision

Accepted for the declared production provider and settlement boundary. Select zero effect for `NotInvoked`, the matching admitted Task-family maximum for `Invoked`, and only component-wise-contained Control actuals. Preserve scheduler and ledger rejection as independent defenses. This satisfies EXP-0028 O20 without installing or endorsing any partial Weight fragment; EXP-0065 still owns exact regeneration and production artifact identity.
