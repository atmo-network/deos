## Interpretation

Pipeline collection is neither a second scheduler source owner nor Action collection. It occurs once only when admitted Idle User service opens a Pipeline; the complete User owners include that work once, while System and non-Opening Running/Suspended service select none. Head decoding changes the collection primitive's resource envelope, so the empty-head diagnostic is rejected as the complete collection input. The complete nonzero-Step benchmark validates composition without subtracting overlapping proof or timing.

Use the complete maximum-head User zero-Step owner for zero-Step Opening and retain the complete User nonzero-Step Opening owner; within those inclusive owners, select exactly one large-head-qualified Pipeline collection operation and receipt for Idle User service. Select none for System or non-Opening phases.
