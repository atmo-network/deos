## Decision Question

Does every reachable Opening, Running, Suspended, wakeup, latch, lifecycle and failure transition retain exactly one Actor-owned continuation while the scheduler owns only order, cutoff, Q1, admission, fairness and accounting?

## Governing Specification

- `Exact section`: `template/pallets/actors/docs/specification.en.md` §§2, 4, 6–9 owns Contract, Pipeline, Continuation, Trigger, scheduling and lifecycle semantics; `docs/actors-resource-policy.specification.en.md` owns scheduler admission/accounting.
- `Invariant`: Actor owns continuation, lifecycle, cursor, attempt, retry and latch state; scheduler owns service order and resource admission; adapters return typed outcomes and own no retry authority.
- `Reopen trigger`: Any second continuation/retry owner or reconstructed process state requires specification reopening.

## Context and Hypothesis

- `Reason`: Accepted EXP-0028 decides phase-accounting ownership but does not itself certify the later G7 transition matrix against the current EXP-0095 implementation.
- `Hypothesis`: Current transitions preserve one canonical Actor-owned continuation and never reconstruct it from Contract, scheduler, Trigger or adapter state.
- `Materiality`: Duplicate or missing continuation authority can replay committed effects, lose prefixes or create a parallel scheduler.

## Baseline and Candidates

The sole candidate is current frozen C1 on EXP-0095. EXP-0028 is historical scoped input, not a substitute for current transition evidence.

## Controls

- `Controlled variables`: EXP-0095 source/binding, C1 FIFO/cutoff/Q1/causal semantics and existing typed adapter outcomes.
- `Changed variables`: None; this is an ownership audit.
- `Confounders`: Resource Weight ownership is not process-state ownership; Contract data is not mutable Continuation; scheduler references are not cursor authority.

## Benchmark Class, Workloads, and Criteria

- `Class`: Source-and-test ownership audit with a compact transition matrix and one regression owner.
- `Workload`: Opening, Running, short/long Suspended retry, Wakeup return, Manual/reactive latch, pause/resume, cancel/close, Contract replacement, exhaustion and typed failure.
- `Metrics`: Source authority, transition atom, destination authority, cursor/prefix preservation, scheduler reference count and external effect count.
- `Acceptance`: Every row names one source, one transactional transition, one destination and one existing falsification test; no adapter or scheduler stores an independent Continuation.
- `Rejection`: Reconstructed cursor/attempt state, duplicate retry scheduling, compensation/replay, or lifecycle mutation that leaves two process authorities.

Current source places mutable Continuation in `ActorRunHead`/`ActorRunPayload`; `write_run_state` is test/benchmark-only and validates coherence. Production transitions use loaded authority and transactional source/successor methods. Contract stores authored immutable plan, hot/control state owns lifecycle/latch/reference metadata, scheduler stores order references, and adapters return typed effects/failures without cursor, attempt or retry storage.

## Derived Metrics

Ten required transition families map to one Actor-owned Run authority and zero adapter-owned continuation stores. The consolidated retry regression now asserts paired Run tiers and mutually exclusive Ready/Wakeup references across short retry, long retry and terminal completion while preserving cursor/prefix and one Cycle start.

## Statistical / Variance Notes

Deterministic source/test audit; throughput, timing and Weight sufficiency are outside scope.

## Result

The current source/test matrix and consolidated regression support sole Actor continuation ownership across all declared transition families.

## Interpretation

Scheduler references decide when an Actor may run, never what cursor/attempt state exists. Trigger and lifecycle state can gate or terminate a process but do not reconstruct Continuation. Adapter outcomes are inputs to Actor-owned transition logic.

## Decision

Accepted. Actor owns the sole mutable Continuation; scheduler references are mutually exclusive eligibility/order authority, and Contract, Trigger and adapters do not reconstruct process state.

## Rejected Alternatives and Tradeoffs

- `EXP-0028 automatic reuse`: Rejected because current transition ownership needs explicit source/test linkage.
- `Storage-name inference`: Rejected because a reference, Contract or hot state can participate without owning Continuation.
- `Adapter retry state`: Rejected by the governing one-Continuation contract unless current evidence falsifies it.

## Validity

Establishes current per-row ownership and consolidated representative Ready/short-retry/long-Wakeup/terminal regression closure. Does not establish independent backpressure safety or release acceptance.
