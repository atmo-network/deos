# DEOS Backlog

> Open framework work only. Specifications own normative behavior; code and tests own implementation and regressions; generated artifacts own resource bindings; Experiment Records own physical decision evidence. Remove completed implementation history instead of preserving a chronological diary.
>
> DEOS `0.7.x` is fresh-genesis and no downstream product network may launch before `1.0`. This plan authorizes local convergence of `0.7.27`; it does not authorize publication, deployment, history rewriting, pushing, tagging, signing, or account mutation.

- [ ] `Actors/Current Baseline Measurement`: Before any optimization or Weight rebinding, measure the post-cut tree as is and record it as the reference coordinates for every later comparison: regenerated Actors benchmark coefficients under both `MaxEncodedLen` and measured ProofSize; per block, the fixed Actor Control overhead with zero Steps, the marginal Control per admitted Step and the Task-effect cost, each in RefTime and ProofSize; distinct storage keys read and written per Step, attributed to owner (process, ring, deadline, run, Contract, fee, effect); and Steps per block at saturation for the W1 Transfer ledger. Exit with one reproducible local command set and a table of those coordinates, not a new Experiment Record.
- [ ] `Actors/Legacy Carrier Removal`: Delete the state-unreachable pre-cutover carrier: `ActorReadyFrameChunks`, `ActorReadyHead/Tail/Occupancy`, `ActorWaitingFrameChunks`, `ActorWaitingHeads`, `ActorControlLocators`, `ActorUnsignaledControlCells`, the unused `PrepassExecutionCutoff`, the `queue_ticket` and `wakeup_pointer` hot-state fields, and every production branch that tests them for absence (about seventy call sites). Keep behavior identical (specification §3), regenerate affected Weight only in the coordinated binding, and record the before/after per-Step reads against the baseline.
- [ ] `Actors/Residence Projection`: Make the public residence view match specification §3.1 and §13.3. `actor_eligibility` still derives placement from the legacy `queue_ticket`/`wakeup_pointer` hot fields, which canonical Actors keep `None`, so every Active Actor reports `Unplaced`; replace `ActorActivationPlacement` with the process residence (`Live`, `Pending`, `Deadline` key, `Parked`, `Disabled`) in the same ABI change as `Actors/Legacy Carrier Removal`. The web client's `readActorControlProjection` classifies an Actor without a legacy locator as absent or Dormant, so the Automation widget shows canonical Active System Actors as missing and every row as "FIFO: not queued"; read the canonical semantic owner and the eligibility residence instead, and drop the FIFO row.
- [ ] `Actors/Prepass Budget Feasibility`: Certify in both Weight dimensions that the mandatory Prepass (cutoff, one Block-then-Tick Deadline quantum, the bounded parked-balance dependency scan and finalization headroom) plus one maximum admitted Service Step fits the exact one-third Actor Control cap (`303,433,283,909` RefTime / `676,150` ProofSize) under the current block ceiling, preserving fixed/context work and both Shared Economic base turns. The retained `183,080` ProofSize screen is a stale-coefficient necessary check, not the certificate. This is the release go/no-go: if no fit exists without weakening semantics, stop for an explicit architecture decision rather than tune a ratio or raise a single ceiling.
